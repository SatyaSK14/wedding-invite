# Satyajeet & Chetana — Royal Heritage Wedding Invitation

A responsive static wedding invitation site using HTML, CSS, an ornate SVG illustration, and a small JavaScript navigation helper. No server or database is required.

## Publish with GitHub Pages (one-time setting)

1. Open **Settings → Pages**: https://github.com/SatyaSK14/wedding-invite/settings/pages
2. Under **Build and deployment → Source**, choose **GitHub Actions**.
3. Open the **Actions** tab and check the workflow named **Deploy wedding invitation to GitHub Pages**. It runs on each push to `main`; you can also run it manually.
4. When the deployment succeeds, visit https://satysk14.github.io/wedding-invite/

## Design notes

The site uses an ivory parchment and antique-gold palette with burgundy typography, an ornate SVG palace/mandap scene, responsive event cards, and an accessible mobile navigation menu. It has no RSVP form and does not collect guest information.
